# My Picks 위시리스트 스튜디오

29CM와 무신사 상품을 조사해 네이버 블로그 위시리스트 초안을 준비하는 개인 사이트입니다. 트렌드 레터, 선택적인 취향 참고 상품, 초안 편집·복사 기능이 있습니다. 실제 블로그 발행은 사용자가 직접 합니다.

## 바로가기

- [My Picks 위시리스트 스튜디오](https://my-picks-wishlist-studio.sooyeon-jun-0389.chatgpt.site/)
- [블로그 자동화 발표 자료 PDF](docs/blog-automation-presentation.pdf)

## 이용 흐름

1. ‘취향 알려주기’에 29CM·무신사 상품 링크를 붙여 넣으면 브랜드·상품명·색상·대표 사진을 읽어 저장합니다. 마음에 든 이유는 선택적으로 적을 수 있습니다.
2. 새로 저장한 취향 상품은 바로 다음 위시리스트 초안에서 모두 검토합니다. 실제 사진의 핏과 분위기를 새 후보와 비교하고, 반영 근거를 글 밖의 비공개 기록으로 남깁니다. 취향 상품을 그대로 글에 넣을 필요는 없습니다.
3. ‘초안 확인’에서 글을 수정하거나 복사하여 네이버 블로그에 붙여넣습니다.
4. 트렌드 레터에서 출처와 함께 패션 흐름을 읽거나 새 레터를 저장합니다.

상품과 글은 Sites D1에 저장됩니다. 로그인하지 않은 방문자는 위시리스트 글과 트렌드 레터를 읽을 수 있습니다. 상품 메모와 말투·취향 설정은 공개하지 않으며, 글·레터·상품을 수정하는 기능은 사이트 소유자만 사용할 수 있습니다. 같은 브랜드의 다른 모델은 허용하고, 이미 글에 사용한 모델은 29CM와 무신사를 통틀어 중복 제외합니다. 다른 색상을 직접 다시 소개할 때만 예외를 표시해 저장할 수 있습니다.

## 예약 작업

요청된 월·수·금 오전 8시(Asia/Seoul) 자동 준비 절차는 [AUTOMATION.md](AUTOMATION.md)에 적었습니다. 사이트의 `/mcp` 도구가 저장된 상품과 말투 기준을 읽고 초안·레터를 저장합니다. 예약 작업을 연결하기 전까지 화면의 작성 일정은 계획된 발행 리듬을 나타냅니다.

## 개발

`npm run dev`로 로컬 미리보기를 실행합니다. 데이터베이스 스키마 변경 후 `npm run db:generate`로 마이그레이션을 생성합니다. 예약 작업이나 사이트 배포 절차는 Sites 플러그인의 관리 흐름을 따릅니다.
